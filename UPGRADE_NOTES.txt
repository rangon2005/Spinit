Spinit — Chat-first + Ludo upgrade

1. Match screen now opens with chat only. The game area is hidden until a game is explicitly selected.
2. A single Games button opens four game options with a slide-down animation.
3. Truth/Dare no longer opens automatically after a match starts.
4. When a game is selected, the game area and chat share the desktop screen roughly 50/50, matching the previous split layout.
5. Chat backgrounds are painted directly on the panel/message area with a lighter overlay so the supplied images are visible.
6. Ludo was rebuilt around the supplied 15x15-style board image. It uses two pawns per player, server-authoritative dice, a 52-cell track, safe squares, capture, 6-to-enter, extra-turn-on-6 and exact home movement.
7. Ludo adds dice-roll animation and pawn movement/hop animation.
8. The player's assigned red/green side is highlighted on the board.
9. Production frontend config points to the existing Render matchmaking service:
   wss://spinit-matchmaking.onrender.com/ws/match
   https://spinit-matchmaking.onrender.com
