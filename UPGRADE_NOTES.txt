Spinit final UI/game update — 2026-09-30

Changes:
- Removed the visible Alpona Live animation and QUICK room label.
- Replaced the header's round logo animation with a red premium mandala-style animation with no text inside the graphic.
- Rock Paper Scissors is now a 5-round, 1-point-per-round match; first to 5 points wins, with a draw after 5 rounds if tied. Player names and points are shown below the choices.
- Guess the Color is now sequential: Player A locks a secret -> Player B guesses -> Player B locks a secret -> Player A guesses. Three rounds total; final score decides the winner, with draw on equal score.
- Color buttons have live glow animation and lock after selection/guess.
- End button immediately collapses the game workspace back to full-screen chat and syncs the state to both players.
- Quick matchmaking queue now pairs the whole ready batch, retries stale queue entries, caps queue size, and periodically cleans/pairs waiting clients for smoother bursts of concurrent users.

2026-09-30 media/GIF patch:
- Removed duplicate small sticker launcher; one direct sticker launcher remains.
- Quick Match photos and voice notes now use the reliable WebSocket relay as a bounded chat media packet so both sender and opponent receive the same media.
- Added cartoon GIF category with Tom & Jerry, Ben 10, Pokemon, Naruto and Dragon Ball Z GIF assets.
- Increased selectable chat send/receive sound volume; default remains Off.
- Added distinct leaderboard finish sound.
- Guess the Color now pauses 0.5s between guess and the next secret-color selection.
- Preserved 3-color buttons per round.
